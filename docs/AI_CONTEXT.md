# AI Project Context – The Reform Room

## Projektübersicht

Dieses Repository enthält den vollständigen Website-Code für das Kundenprojekt "The Reform Room".

Die Website basiert auf:

- Next.js
- React
- TypeScript
- Tailwind CSS

Das Ziel ist es, die Website professionell weiterzuentwickeln, ohne bestehende Funktionen zu beschädigen.

---

# Was NICHT im Repository enthalten ist

Folgender Ordner wird separat übergeben:

reform-room-design-export/

Dieser enthält unter anderem:

- GRUNDPROMPT.md
- LEISTUNGSUMFANG.md
- INHALTE.md
- BRAND.md
- PROJEKT.md
- TECHNISCH.md
- Logo-Dateien

Diese Dateien dienen ausschließlich als Projektdokumentation und Kundenkontext.

---

# Environment Variablen

Die Zugangsdaten befinden sich NICHT im Repository.

Diese werden später über Netlify oder lokal über `.env.local` gesetzt.

Beispiele:

- BREVO_API_KEY
- BREVO_LIST_ID
- BREVO_NOTIFY_EMAIL
- BREVO_SENDER_EMAIL
- NEXT_PUBLIC_SITE_URL
- NEXT_PUBLIC_LAUNCH_DATE
- NEXT_PUBLIC_GA_MEASUREMENT_ID

Diese Werte dürfen niemals in GitHub hochgeladen werden.

# Arbeitsweise

Bevor Änderungen vorgenommen werden:

- bestehende Komponenten analysieren
- bestehendes Design respektieren
- keine funktionierenden Bereiche unnötig umbauen
- bestehende Komponenten möglichst wiederverwenden

Neue Features sollen immer zum bestehenden Design passen.

---

# Ziel

Die Website soll modern, schnell, hochwertig und wartbar bleiben.

Bei allen Änderungen gilt:

- saubere Komponenten
- responsive
- performanter Code
- TypeScript sauber halten
- bestehende Struktur beibehalten
